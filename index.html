学修デザインシートの8つのマス

ひとコマの授業を「一枚の地図」として組み立てるためのシートです。0番から7番へ、時計回りに一周します。

6継続授業のあとに続くこと
7応用達成感を与える閉じの儀式
0準備教師が事前に持っている条件
1期待始まる前につくる「やってみたい」
5確認学びを振り返り、意味づける
4反応Output｜学んだことを使う
3感知Input｜情報を受け取る
2解放安心・安全と、全体像の提示

0 準備 → 1 期待 → 2 解放 → 3 感知 → 4 反応 → 5 確認 → 6 継続 → 7 応用 → 0 へ戻る
上の段を左から右へ、右の辺を下りて、下の段を右から左へ、左の辺を上る。時計回りに一周します。

このシートには アクセラメンツ（Accelements） という加速学習理論がバックボーンにあります。NLPとアクセラレイテッド・ラーニングを、教育現場で使える形に落とし込んだものです。中心にある考え方はひとつだけ。

人は8段階の学修サイクルをたどって学ぶ。8段階を意図的に通すと、学びが定着する。途中を飛ばすと、頭ではわかったつもりでも、体には残らない。

各マスの意味

0

準備

授業が始まる前に、教師の側が持っている情報と条件です。タイトル・ゴール・対象・時間・前提条件が基本セット。

これを渡せば、他の人が同じ授業を再現できる
1

期待

始まる前に「楽しそう」「やってみたい」をつくる仕掛け。事前の予告、教室の掲示、机の配置、入ってきたときに目に入るもの。学習は席に着く前から始まっています。

低学年なら、掲示や入口の実物が効く
2

解放

体と頭を学習モードに切り替える時間。緊張をほぐし、今日の流れを示します。安心・安全の確保と、全体像の提示がセットです。

Good & New／流れの板書／軽い復習
3

感知（Input）

学修者が情報を受け取る時間。視覚・聴覚・体感覚（VAK）のうち、できれば2つ以上が混ざる設計にします。

2感覚以上を組み合わせる
4

反応（Output）

学んだことを実際に使う時間。声に出す、書く、人に説明する、手を動かす。1つだとアウトプット不足で、感知したものが定着しないまま終わります。

アウトプットの機会は3つ以上
5

確認

学んだことを振り返り、自分の中で意味づける時間。大事なのは「いま自分は何を学んだのか」を言語化する機会があることです。

個人 → グループ → 全体 の順で広げる
6

継続

授業が終わったあとも続く学び。家で何をするか、次の授業とどうつなぐか。欲張ると続きません。

1〜2個だけ書く
7

応用

いちばん誤解されるマスです。「応用問題を出す枠」ではありません。達成感を与える閉じのセレモニーです。認定証、拍手、写真、スタンプ——形は何でもよくて、サイクルを締める装置を用意します。

「学んだ」で終わらせず「やり遂げた」を体に残す

かきかたのコツ

最初の1枚は完璧でなくて構いません。埋まらないマスがあっても大丈夫です。

全部埋めなくていい

最初は3〜4マスから始めるくらいでちょうどいいです。白紙を前に固まるより、書けるところから。

付箋で書く

直接書き込むと動かせません。付箋に1つずつ書いて貼れば、何度でも剥がして貼り直せます。

3と4を分けて考える

「説明する→問題を解かせる」で混ざりがちな Input と Output を、意図して分ける。これだけで組み立てが変わります。

分けて、つなげる

アクセラメンツの根っこにある発想です。段階を分けて意識し、そのうえで一周つなぐ。

この90分そのものが、8マスでできています

ワークショップの進み方は、シートの8マスと対応しています。あなたは「学修デザインシートを学ぶ」のではなく、「学修デザインシートに沿って学ぶ」ことになります。

開講前の支度0 準備
オープニング1 期待
アイスブレイク2 解放
レクチャー3 感知（Input）
ハンズオン4 反応（Output）
共有と振り返り5 確認
持ち帰りの確認6 継続
クロージング7 応用

ツールのセットアップ

最初の1回だけ必要な作業です。5分ほどで終わります。

  1. シートを自分のドライブにコピーする

    bit.ly/ldsheet を開いて テンプレートを使用 を押します。自分のドライブにコピーができます（プログラムも一緒にコピーされます）。

  2. Apps Script を開く

    コピーしたシートのメニューから 拡張機能 → Apps Script。コードはすでに入っているので、書く必要はありません。

  3. ウェブアプリとしてデプロイする

    右上の デプロイ → 新しいデプロイ → 種類を ウェブアプリ に。

    • 実行するユーザー：自分
    • アクセスできるユーザー：自分のみ

    設定したら デプロイ を押します。

  4. アクセスを承認する（ここでつまずきます）

    アクセスを承認 を押すと、「Googleはこのアプリを検証していません」 という警告が出ます。自分専用に自分でデプロイしたアプリなので、これは想定どおりの表示です。

    • 画面左下の小さな文字をクリック（表記は「詳細」「高度な」「Advanced」など、ブラウザの言語設定や翻訳の有無で変わります）
    • 開いた 「（アプリ名）に移動（安全ではないページ）」 をクリック
    • 許可 をクリック

    「安全な場所へ戻る」を押すとやり直しになります。押さないでください。

  5. 表示されたURLを開いて、APIキーを入れる

    デプロイ完了後に表示されるウェブアプリのURLを開きます。初回だけ「AI設定」が自動で開くので、Google AI Studio で取得したGemini APIキーを貼って保存。以降は再入力不要です。

    URLはブックマークしておくと、次から一発で開けます。

APIキーで403エラーが出たら

2026年7月ごろから、Google側で無料枠のプロジェクトが突然「denied access」になる事例が出ています。ツール側に日本語の案内を出すようにしてあります。別のGoogleアカウントで取り直したキーを登録すると通ることが多いです。当日つまずいたら会場で声をかけてください。

「サブスク課金」と「API課金」は別物です

Google AI Pro などに課金していても、APIキーの利用枠は別枠です。逆に、無料枠のAPIキーでもこのツールは動きます。

ツールでできること

第2部で触るのは、おもにこの4つです。

AIで8マスを生成・調整する

タイトル・教科・学年を入れると、8マスの案が出ます。理論に沿ったプロンプト（3感知は2感覚以上、4反応は3つ以上、6継続は1〜2個、7応用はセレモニー…）を仕込んであるので、ただの当たり障りのない案にはなりません。

付箋モードで、自分の意図を先に置く

上部の アドバンスド（付箋） に切り替えると、付箋トレイが出ます。「これは絶対やりたい」をマスにドラッグしておくと、AIはそれを最優先で活かした案を作ります。第1部で紙に貼った付箋を、そのまま持ち込むイメージです。

指導案をGoogleドキュメントで出す

指導案を作成（Docs） で、研究授業フォーマットの指導案が生成されます。2解放→導入（めあて）、3感知・4反応→展開、5確認→振り返り→まとめ→7応用のセレモニー、という対応で組み立てます。

他のAIに引き継ぐ（md）

シートの内容と8マスの読み方、指導案化の依頼文をまとめたMarkdownをコピー／ダウンロードできます。ChatGPTでもClaudeでも、貼れば続きができます。ここだけはAPIキー不要です。

よくある質問

当日いちばん聞かれることを、先に置いておきます。

全部のマスを埋めないとダメですか？

埋めなくて大丈夫です。最初は3〜4マスから始めるくらいでちょうどいいです。

「7 応用」って、応用問題のことですか？

違います。達成感を与える閉じのセレモニーです。全員で拍手、スタンプ、写真、「次も楽しみだね」の一言。30秒で終わるものでいいので、サイクルを締める装置を置きます。

子どもが小さくて「期待」が難しいです。

小学校低学年なら、教室に貼る絵や、入口に置く実物が「期待」になります。事前情報よりも、その場の環境のほうが効くことが多いです。

手書きとデジタル、どちらがいいですか？

最初の1枚は紙をおすすめします。デジタル版がAIの案を出したときに、その良し悪しを自分で判断できる目を、先に作っておきたいからです。手書きは目的ではなく、判断力をつけるための入口です。

学校のPCでも動きますか？

動かない可能性が高いです。多くの自治体でApps Scriptのデプロイや外部APIの利用が制限されています。個人所有のPCを持ってきてください。

APIキーは有料ですか？

無料枠でも動きます。ただし無料枠は制限が厳しく、混み合うと止まることがあります。ツール側には、モデルを選び直したり、標準モデルに自動で切り替えたりする仕組みを入れてあります。

当日にセットアップが間に合わなかったら？

紙のシートだけでも第1部は完結します。第2部も、隣の方の画面を一緒に見る形で参加できます。あとから自分の環境で追体験できるように、このページは大会後も残しておきます。
